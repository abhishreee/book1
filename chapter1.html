Computer System

Introduction of Computer

A computer is an electronic device that accepts data as input, processes it according to instructions and produces meaningful information as output. It can perform calculations and other tasks quickly and accurately.

1.1.1 Definition, Characteristics and Application of Computer

Definition

A computer is an electronic programmable device that accepts data, processes it and produces useful information as output.

Characteristics

  • High speed
  • Accuracy
  • Large storage capacity
  • Diligence
  • Versatility
  • Automation
  • Reliability

Applications

Computers are used in education, banking, healthcare, business, communication, entertainment, transportation, science and research.

1.1.2 Evolution of Computer Technology

The development of computers has passed through five generations.

  • First Generation: Used vacuum tubes.
  • Second Generation: Used transistors.
  • Third Generation: Used integrated circuits (ICs).
  • Fourth Generation: Used microprocessors.
  • Fifth Generation: Focuses on artificial intelligence and advanced technologies.

1.1.3 Measurement Unit of Processing Speed and Storage Unit

Processing speed is measured in Hertz (Hz), commonly expressed in MHz and GHz. Storage capacity is measured using units such as byte, KB, MB, GB and TB.

  • 1 Byte = 8 bits
  • 1 KB = 1024 Bytes
  • 1 MB = 1024 KB
  • 1 GB = 1024 MB
  • 1 TB = 1024 GB

1.1.4 Super, Mainframe, Mini and Microcomputers

Supercomputer: The fastest and most powerful computer used for complex scientific calculations and research.

Mainframe Computer: A powerful computer used by large organizations to process large amounts of data and support many users.

Minicomputer: A medium-sized computer that can support multiple users and is more powerful than a microcomputer.

Microcomputer: A small computer designed mainly for individual use, such as desktop computers and laptops.

1.1.5 Mobile Computing and its Application

Mobile computing refers to using portable computing devices and wireless networks to access and process information from different locations. Smartphones, tablets and laptops are examples of mobile computing devices.

Applications: Mobile banking, online education, GPS navigation, social media, online shopping and video conferencing.

1.2 Computer System and I/O Devices

A computer system is a combination of hardware and software that works together to process data. Input devices enter data into the computer, while output devices display the processed information.

1.2.1 Concept of Computer Architecture and Organization

Computer Architecture refers to the design and functional structure of a computer system.

Computer Organization refers to how the physical components of a computer are arranged and connected to perform different operations.

1.2.2 Components of Computer System

  • Input Unit: Accepts data and instructions from the user.
  • Output Unit: Displays the processed information.
  • Processing Unit: Processes data and instructions.
  • Memory Unit: Stores data, instructions and results.
  • Storage: Stores data and programs for long-term use.

1.2.3 Microprocessor

A microprocessor is an integrated circuit that performs the main functions of a CPU.

Clock Speed: The number of operations a processor can perform per second, measured in Hz, MHz or GHz.

Word Length: The number of bits a processor can process at one time. Common word lengths are 8-bit, 16-bit, 32-bit and 64-bit.

Components: ALU, Control Unit and Registers.

Functions: It performs arithmetic, logical and control operations and processes instructions.

1.2.4 Bus System

A bus is a communication pathway used to transfer data and signals between different components of a computer.

  • Data Bus: Transfers data between components.
  • Address Bus: Carries the address of data or memory locations.
  • Control Bus: Carries control signals between components.

1.2.5 Primary Memory

Primary memory is the main memory directly accessible by the CPU. It stores data and instructions required during processing.

RAM: Volatile memory used to store data and programs temporarily.

ROM: Non-volatile memory that stores permanent instructions.

Cache: A small and high-speed memory used to provide frequently needed data to the CPU quickly.

Buffer: Temporary storage used while transferring data between devices.

Types of RAM: SRAM and DRAM.

Types of ROM: PROM, EPROM and EEPROM.

1.2.6 Secondary Memory

Secondary memory is non-volatile memory used to store data and programs permanently. It has a larger capacity than primary memory.

  • Magnetic Disk: Stores data using magnetic technology. Example: Hard Disk.
  • Flash Memory: Electronic storage used in SSDs, memory cards and USB drives.
  • Optical Disk: Uses laser technology to store data. Examples: CD and DVD.
  • External Storage Device: Portable devices used for storing and transferring data.
  • Memory Stick: A small portable USB storage device used to store and transfer data.

1.2.7 Input Devices

  • Keyboard: Used to enter text, numbers and commands.
  • Mouse: Used to point, select and open objects.
  • Scanner: Converts physical documents into digital form.
  • Light Pen: Used to select or draw objects on a screen.
  • OMR: Reads marked areas on specially designed forms.
  • OCR: Converts printed text into editable digital text.
  • BCR: Reads information from barcodes.
  • MICR: Reads characters printed with magnetic ink, mainly used in banking.
  • Touch Screen: Allows users to operate a device by touching the screen.
  • Microphone: Converts sound into digital signals.
  • Digital Camera: Captures images and videos in digital form.

1.2.8 Output Devices

Monitor

A monitor is a visual output device used to display text, images and videos. LCD and LED are common types of monitors.

Printer

A printer produces a hard copy of text and images on paper.

  • Dot Matrix: Prints by striking pins against an ink ribbon.
  • Inkjet: Prints by spraying tiny droplets of ink.
  • Laser: Uses laser technology and toner to produce prints.

Speaker

A speaker is an output device that converts electrical signals into sound.

1.2.9 Hardware Interfaces

Hardware interfaces are connection points that allow different hardware devices to communicate with a computer.

  • Parallel Port: Transfers multiple bits of data at the same time.
  • Serial Port: Transfers data one bit at a time.
  • USB Port: Connects devices such as keyboards, mice and storage devices.
  • HDMI: Transfers digital audio and video signals.
  • Expansion Slots: Allow additional hardware cards to be connected to the motherboard.

Conclusion

Computer systems consist of various hardware components that work together to process and store data. Understanding these components, memory, buses, input and output devices helps us understand the basic working of a computer.
