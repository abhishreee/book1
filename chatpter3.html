Concept of Software

3.1 Concept of Software

3.1.1 Definition of Software

Software is a collection of programs and instructions that tells a computer how to perform specific tasks. It helps the user interact with computer hardware.

3.1.2 Categories of Software

  • System Software: Controls and manages computer hardware and provides a platform for other software.
  • Utility Software: Helps maintain, protect and manage the computer system.
  • Application Software: Designed to perform specific tasks for users.
  • Web-Based Software: Software that runs through a web browser using the internet.
  • Mobile Apps: Applications designed to run on mobile devices such as smartphones and tablets.

3.2 Concept of Operating System

3.2.1 Introduction to Operating System

An Operating System (OS) is system software that manages computer hardware, software resources and provides an interface between the user and the computer. Examples include Windows, Linux, UNIX and Android.

3.2.2 Role of Operating System

  • Acts as an interface between user and hardware.
  • Manages computer resources.
  • Controls the execution of programs.
  • Provides security and user management.

3.2.3 Functions of an Operating System

  • Process management
  • Memory management
  • File management
  • Device management
  • Security management
  • User interface management

3.2.4 Operating System Terminology

  • Multiprogramming: Running multiple programs by keeping them in memory at the same time.
  • Multitasking: Allowing a user to perform multiple tasks at the same time.
  • Multiprocessing: Using two or more processors to execute processes.
  • Distributed: A system where multiple computers work together and share resources.

3.3 Windows Operating System

3.3.1 Introduction to GUI Based Operating System and Its Features

A GUI (Graphical User Interface) based operating system allows users to interact with a computer using graphical elements such as icons, windows, menus and buttons. Windows is a popular GUI-based operating system.

  • Easy to use
  • Graphical interface
  • Multitasking
  • File and folder management
  • Supports various hardware devices

3.3.2 Working in Desktop Application and Window Environment

The Windows desktop provides access to applications, files and system settings. Users can open, minimize, maximize and close application windows.

3.3.3 Manage Files and Folders with File Explorer

File Explorer is a Windows tool used to create, copy, move, rename, delete and organize files and folders.

3.3.4 Customize the Start Screen and Desktop

Windows allows users to customize the desktop by changing wallpapers, themes, icons, taskbar settings and other display options.

3.3.5 Installing and Removing Devices

Windows can detect and install hardware devices such as printers, keyboards and storage devices. Devices can also be removed or uninstalled when required.

3.3.6 Manage Passwords and Privacy Levels

Windows provides user accounts, passwords and privacy settings to protect personal information and control access to the computer.

3.3.7 Use of Control Panel, System Tools and Accessories

Control Panel is used to manage system settings. System tools help maintain the computer, while accessories include useful programs such as Calculator, Notepad and Paint.

3.4 Open Source and Mobile Operating System

3.4.1 Concept of Open Source Operating System

An open source operating system is an operating system whose source code is available for users to view, modify and distribute according to its license.

3.4.2 Introduction to Linux and UNIX

Linux is an open source operating system widely used in computers, servers and other devices. UNIX is a powerful multi-user and multitasking operating system mainly used in servers and professional systems.

3.4.3 Linux Distributions

A Linux distribution is a version of Linux that includes the Linux kernel, system tools and applications.

  • Ubuntu
  • Fedora
  • Debian
  • Linux Mint
  • Arch Linux

3.4.4 Concept of Mobile Operating System

A mobile operating system is software designed to manage mobile devices such as smartphones and tablets. It manages hardware, applications, files and communication features.

3.4.5 Types of Mobile Operating System

  • Android
  • iOS
  • HarmonyOS
  • KaiOS
