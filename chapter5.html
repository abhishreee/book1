Programming Concepts and Logics

5.1 Programming Concept

5.1.1 Introduction to Programming Languages

A programming language is a formal language used to write instructions that a computer can understand and execute. It helps programmers develop software, applications and solve different problems.

5.1.2 Low Level, High Level and 4 GL Programming Languages

  • Low Level Language: A language close to machine language and hardware. Machine language and assembly language are examples.
  • High Level Language: A user-friendly language that is easier to read and write. C, C++, Java and Python are examples.
  • 4 GL: Fourth-generation languages are designed to make programming easier and require less code. SQL is a common example.

5.1.3 Compiler, Interpreter and Assembler

  • Compiler: Translates the entire high-level program into machine code at once.
  • Interpreter: Translates and executes a program line by line.
  • Assembler: Converts assembly language instructions into machine language.

5.1.4 Syntax, Semantic and Runtime Errors

  • Syntax Error: An error caused by violating the rules of a programming language.
  • Semantic Error: An error in the meaning or logic of a statement.
  • Runtime Error: An error that occurs while the program is running.

5.1.5 Control Structures

Control structures determine the order in which statements of a program are executed.

  • Sequence: Statements are executed one after another.
  • Selection: A decision is made between different alternatives.
  • Iteration: A set of statements is repeated until a condition is satisfied.

5.1.6 Program Design Tools

  • Algorithm: A step-by-step procedure for solving a problem.
  • Flowchart: A graphical representation of an algorithm using standard symbols.
  • Pseudocode: A simple, informal description of a program written using programming-like statements.

5.1.7 Absolute Binary, BCD, ASCII and Unicode

  • Binary: A number system that uses only 0 and 1.
  • BCD: Binary Coded Decimal represents each decimal digit using four binary bits.
  • ASCII: A character encoding system used to represent letters, digits and symbols using numeric codes.
  • Unicode: A universal character encoding system that supports characters from many languages.

5.2 C Programming Language

5.2.1 Introduction and Features of C Language

C is a general-purpose, structured programming language developed by Dennis Ritchie. It is widely used for system software, application development and embedded systems.

Features of C:

  • Simple and efficient
  • Structured programming language
  • Portable
  • Fast execution
  • Supports functions and arrays
  • Rich set of operators

5.2.2 Structure of C Program

A C program generally consists of preprocessor directives, functions, the main() function, variable declarations, statements and comments. 

#include <stdio.h>

int main()
{
    printf("Hello World");
    return 0;
}

5.2.3 C Preprocessor and Header Files

The C preprocessor processes instructions before the program is compiled. Header files contain predefined functions and declarations that can be included in a program.

Example: #include <stdio.h> includes the standard input/output header file.

5.2.4 Character Set Used in C

The C character set includes letters, digits, special symbols and whitespace characters used for writing C programs.

  • Alphabets: A-Z and a-z
  • Digits: 0-9
  • Special symbols: +, -, *, /, %, =, <, > etc.
  • Whitespace characters such as space, tab and newline

5.2.5 Use of Comments

Comments are explanatory statements written in a program that are ignored by the compiler. They make programs easier to understand. 

// Single-line comment

/* Multi-line
   comment */

5.2.6 Identifiers, Keywords and Tokens

  • Identifier: A name given to variables, functions, arrays and other program elements.
  • Keyword: A reserved word having a special meaning in C, such as int, if and return.
  • Token: The smallest individual unit of a C program, such as keywords, identifiers, constants and operators.

5.2.7 Basic Data Types in C

Data Type Purpose
int Stores integer values
float Stores decimal values
char Stores a single character
double Stores larger decimal values with greater precision
void Represents no value

5.2.8 Constants and Variables

A constant is a value that does not change during program execution. A variable is a named memory location whose value can change during program execution. 

const int age = 16;
int marks = 80;

5.2.9 Type Specifier

Type specifiers are used to specify the type of data stored or returned by a variable or function. Common type specifiers in C include int, char, float, double and void.

5.2.10 Simple and Compound Statements

A simple statement is a single statement ending with a semicolon. A compound statement is a group of statements enclosed within curly braces { }.

5.2.11 Operators and Expressions

Operators are symbols used to perform operations on values and variables. An expression is a combination of variables, constants and operators.

  • Arithmetic: +, -, *, /, %
  • Relational: <, >, <=, >=, ==, !=
  • Logical: &&, ||, !
  • Assignment: =, +=, -=, *=, /=
  • Unary: ++, --, +, -
  • Conditional: ? :

5.2.12 Input/Output (I/O) Functions

Input/output functions are used to receive data from the user and display results. Common functions include scanf() for input and printf() for output. 

printf("Enter your age:");
scanf("%d", &age);

5.2.13 Selection Control Statement

Selection statements are used to make decisions based on conditions.

  • if: Executes a statement when a condition is true.
  • if-else: Selects between two alternatives.
  • if-else-if: Checks multiple conditions.
  • Nested if: An if statement placed inside another if statement.
  • switch: Selects one option from multiple cases.

5.2.14 Iteration Control Statement

Iteration statements are used to repeatedly execute a block of statements.

  • while: Repeats statements while a condition is true.
  • do-while: Executes the statements at least once before checking the condition.
  • for: Repeats statements for a specified number of times.
  • Nested Loop: A loop placed inside another loop.

5.2.15 Array

An array is a collection of elements of the same data type stored under one name. Each element is accessed using an index.

  • 1D Array: Stores elements in a single row or list.
  • 2D Array: Stores elements in rows and columns and is commonly used for matrices.

Matrix Addition and Subtraction: Two matrices of the same order can be added or subtracted by performing the operation on their corresponding elements.

5.2.16 String and String Functions

A string is a sequence of characters stored in a character array and terminated by a null character (\0).

Common string functions:

Function Purpose
strlen() Finds the length of a string
strcat() Joins two strings
strcmp() Compares two strings
strrev() Reverses a string
strcpy() Copies one string into another
strlwr() Converts a string into lowercase
strupr() Converts a string into uppercase
