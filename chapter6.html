Web Technology

6.1 Introduction to Web Development

Web development is the process of creating and maintaining websites and web applications. It uses technologies such as HTML, CSS, JavaScript, web browsers and web servers to provide information and services through the Internet.

6.2 Web Browsers and Search Engines

A web browser is software used to access and display webpages on the Internet. Examples of web browsers are Google Chrome, Mozilla Firefox, Microsoft Edge and Safari.

A search engine is an online service used to search for information on the Internet. It provides relevant webpages according to the keywords entered by the user. Google, Bing and Yahoo are examples of search engines.

6.3 Overview of Various Internet and Web Technologies

Internet and web technologies are used to communicate, share information and provide online services. HTML is used to create the structure of webpages, CSS is used for designing and JavaScript is used to add interactivity.

Other technologies such as web servers, databases, URLs, HTTP, HTTPS and cloud computing also play an important role in providing web-based services.

6.4 Content Management System (CMS)

A Content Management System (CMS) is software used to create, manage, edit and publish digital content on a website. It allows users to manage website content without having to write all the code manually. WordPress, Joomla and Drupal are some popular CMS platforms.

6.4 HTML: The Language of the Web

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure webpages. HTML uses tags and elements to organize text, headings, lists, tables, forms, links and multimedia content.

6.4.1 Objectives

The main objectives of HTML are to create the structure of webpages, organize information, create hyperlinks, display multimedia content and provide forms for collecting information from users.

6.4.2 Structure of HTML

An HTML document mainly consists of HTML, HEAD and BODY sections. The HEAD section contains information about the webpage, while the BODY section contains the content displayed in the browser.

6.4.3 Publishing and Hosting

Publishing a website means making it available to users through the Internet. Web hosting provides space on a web server where website files are stored. After a website is hosted, users can access it using its web address.

6.4.4 HTML Tags vs. Attributes

HTML tags define the structure and content of a webpage, whereas attributes provide additional information about HTML elements. Attributes are generally written inside the opening tag.

6.4.5 Basic Tags of HTML

The basic HTML tags include HTML, HEAD, TITLE and BODY. The HTML tag defines the HTML document, HEAD contains information about the document, TITLE defines the webpage title and BODY contains the visible webpage content.

Older HTML also provided attributes for setting foreground colour, background colour and background images. Background sound was also supported by some older browsers.

6.4.6 Heading Tag (H1 to H6) and ALIGN

HTML provides six levels of headings from H1 to H6. H1 is the highest-level heading and H6 is the lowest-level heading. The ALIGN attribute was traditionally used to specify the alignment of headings.

6.4.7 FONT Tag and Attributes

The FONT tag was traditionally used to control the size and colour of text. The SIZE attribute provided seven levels from 1 to 7, while the COLOR attribute was used to change text colour. BASEFONT was used to specify a default font size. SMALL and BIG were used to display relatively smaller and larger text.

6.4.8 Paragraph Formatting (P)

The P tag is used to create paragraphs in an HTML document. It separates different blocks of text and makes the content easier to read.

6.4.9 Break Line (BR)

The BR tag is used to insert a line break in a webpage. It moves the following content to a new line without starting a new paragraph.

6.4.10 Comment in HTML

Comments are notes written in HTML code that are not displayed on the webpage. They are mainly used to explain or organize the code for developers.

6.4.11 Formatting Text

HTML provides different tags for formatting text. Bold, italic, underline, highlighting, superscript, subscript and emphasis can be applied using appropriate HTML elements. Blockquote is used for quoted content, while preformatted text preserves spaces and line breaks.

6.4.12 Ordered List - OL

An ordered list displays items in a particular sequence. It uses OL for the list and LI for individual items. Different numbering styles such as numbers, letters and Roman numerals can be used. START and VALUE can be used to control the numbering of list items.

6.4.13 Unordered List - UL

An unordered list displays items using bullets instead of numbers. The UL and LI tags are used to create an unordered list. Traditional bullet types include disc, circle and square. DL, DT and DD are used to create description lists.

6.4.14 ADDRESS Tag

The ADDRESS tag is used to provide contact or author information related to a webpage or document. It can contain information such as name, address and email address.

Creating Links

Links allow users to move from one webpage or resource to another. The anchor tag is used to create hyperlinks, while the HREF attribute specifies the destination of the link. Links can connect to another HTML document, a different location in the same document or a specific location in another HTML document.

6.4.15 Tables

Tables are used to organize information into rows and columns. The TABLE tag creates a table, TR defines a row, TH defines a heading cell and TD defines a data cell. Tables are useful for presenting structured information clearly.

6.4.16 Forms

HTML forms are used to collect information from users. A form can contain text boxes, radio buttons, checkboxes, text areas and buttons. Forms are commonly used for registration, login, feedback and other data collection purposes.

6.4.17 HTML5 Elements

HTML5 introduced elements for handling multimedia content such as audio and video. The AUDIO and VIDEO elements can be used with SOURCE, TRACK and EMBED elements to provide multimedia and related resources on webpages.

6.4.18 HTML5 Graphics

HTML5 supports graphics through CANVAS and SVG. Canvas provides an area for drawing graphics using scripts, while SVG is used to create scalable vector-based graphics. These technologies are useful for creating graphical content on webpages.

6.4.19 Domain Name and Web Hosting

A domain name is the human-readable address of a website on the Internet. It is easier to remember than an IP address. Web hosting is a service that stores website files on a server and makes them available through the Internet. A website generally uses a domain name along with web hosting to become accessible to users.

6.5 Cascading Style Sheets

6.5.1 Introduction to Cascading Style Sheet (CSS)

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML webpages. CSS can be used to change colours, fonts, spacing, borders, sizes and positioning of webpage elements.

6.5.2 Inline CSS

Inline CSS is written directly inside an HTML element using the STYLE attribute. It is mainly used when a particular style needs to be applied to a single element.

6.5.3 Embedded CSS

Embedded CSS, also called internal CSS, is written inside the STYLE element within the HEAD section of an HTML document. It is useful when styles are required for a single webpage.

6.5.4 External CSS

External CSS is written in a separate CSS file and connected to an HTML document. It is useful when the same styles need to be applied to multiple webpages. It makes the website easier to maintain and update.
