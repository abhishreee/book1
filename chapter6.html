6.1 Introduction to Web Development

Web development is the process of designing, creating and maintaining websites and web applications. It involves technologies such as HTML, CSS and JavaScript. Web development mainly includes front-end development and back-end development.

6.2 Web Browsers and Search Engines

A web browser is software used to access and display webpages on the Internet. Examples are Google Chrome, Mozilla Firefox, Microsoft Edge and Safari. A search engine is an online service used to find information on the Internet using keywords. Examples include Google, Bing and Yahoo.

6.3 Overview of Internet and Web Technologies

Internet and web technologies allow users to communicate, access information and use online services. Some common technologies are HTML, CSS, JavaScript, web servers, URLs, HTTP and HTTPS. These technologies work together to provide web-based services.

6.4 Content Management System (CMS)

A Content Management System (CMS) is software used to create, organize, edit and manage digital content. It allows users to build websites without having advanced programming knowledge. WordPress, Joomla and Drupal are common examples of CMS.

6.4 HTML: The Language of the Web

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of webpages. HTML uses tags and attributes to define different elements such as headings, paragraphs, images, links and tables.

6.4.1 Objectives

  • To understand the basic structure of HTML documents.
  • To learn different HTML tags and attributes.
  • To create and format webpages.
  • To add links, tables, forms and multimedia.

6.4.2 Structure of HTML

An HTML document generally contains DOCTYPE, HTML, HEAD and BODY sections. The HEAD contains information about the webpage, while the BODY contains the content displayed to the user.

6.4.3 Publishing and Hosting

Publishing a website means making it available to users through the Internet. Web hosting provides storage space on a web server for website files. A domain name gives the website a unique and easy-to-remember address.

6.4.4 HTML Tags and Attributes

HTML tags define the elements of a webpage, whereas attributes provide additional information about those elements. Attributes are usually written inside the opening tag.

Comments are notes written inside HTML code that are not displayed on the webpage. They help programmers understand and organize their code.

6.4.16 HTML5 Multimedia Elements

HTML5 introduced elements for adding multimedia to webpages. The AUDIO and VIDEO tags are used to play sound and video. The SOURCE tag specifies the media file, TRACK provides subtitles or captions, and EMBED can be used to include external content.

6.4.17 HTML5 Graphics

HTML5 supports graphics through CANVAS and SVG. Canvas is used to draw graphics using scripts, while SVG is used to create scalable vector graphics. These elements are useful for creating shapes, diagrams and other visual content.

6.5 Cascading Style Sheets (CSS)

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of webpages. CSS can change colors, fonts, spacing, borders, sizes and the position of HTML elements. It makes webpages more attractive and consistent.

6.5.1 Introduction to CSS

CSS separates the design of a webpage from its HTML structure. It allows the same style to be applied to many elements and webpages, making website design easier to manage.

6.5.2 Inline CSS

Inline CSS is written directly inside an HTML element using the STYLE attribute. It is mainly used when a style is required for a particular element. 

Hello World

6.5.3 Embedded CSS

Embedded CSS is written inside the STYLE tag in the HEAD section of an HTML document. It can be used to apply styles to multiple elements on one webpage.

6.5.4 External CSS

External CSS is written in a separate file with a .css extension. The CSS file is connected to the HTML document using the LINK tag. It is useful when the same design needs to be applied to several webpages.
